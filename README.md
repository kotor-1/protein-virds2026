# NEXT-18 PROTEIN 会員価格のご案内（HappinessAC・VIRDS）

HappinessAC と VIRDS の会員向けのご案内ページです。ページの中身は `index.html` の1ファイルだけです（写真も中に入っています）。

公開URL: https://kotor-1.github.io/protein-virds2026/

## 書きかえる場所

`index.html` のいちばん上にある、次の2行だけです。`""` の間にURLをそのまま貼ります。

```
var YOUTUBE_URL = "https://youtu.be/Ykdn5eEfq2I";   // インタビュー動画（YouTube）のURL
var ORDER_URL   = "https://forms.gle/7gFoUogmFqMeprSc6";   // 注文フォームのURL
```

- 注文フォームのボタンは、「確認しました」にチェックを入れたあとで押せるようになります。

## 知っておくこと

- パスワードはかかりません。URLを知っている人は誰でも見られます。
- 検索には出ない設定にしてあります。
